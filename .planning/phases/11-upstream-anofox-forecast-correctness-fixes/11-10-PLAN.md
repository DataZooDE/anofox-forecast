Purpose: UPST-05 (audit H7; upstream report 2026-03-04: TBATS widths far below statsforecast, MSTL
effectively no intervals). Planning-time reading: TBATS `predict_with_intervals` uses
sigma·sqrt(h + 1) — pure random-walk growth that ignores its own trigonometric seasonal states;

values − (trend + remainder + seasonal), which is ~0 for an exact decomposition. Both are
fixable here: TBATS is a linear innovations state-space model (exact variance via c_j = w'F^(j−1)g,
as R forecast::tbats and statsforecast compute it), and MSTL's intervals follow from its trend
model, as statsforecast builds them. GARCH was settled in 11-09.
Output: tbats/model.rs and mstl_forecaster.rs interval code, statsforecast reference generator +
fixture, reference tests, CHANGELOG, PR ready.
