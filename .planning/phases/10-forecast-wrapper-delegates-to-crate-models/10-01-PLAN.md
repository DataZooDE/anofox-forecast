<objective>
Make the single-series forecast wrapper return what the crate model actually produced: prediction
intervals from `Forecaster::predict_with_intervals(h, level)`, fitted values and residuals from
`fitted_values()` / `residuals()`, and an MSE computed from those residuals over non-interpolated
points. Replace the four hand-rolled baselines (Naive, SeasonalNaive, SMA, RandomWalkDrift) with
their crate types, delete the fabricated-interval and SES(α=0.3)-fitted helpers, and make series
input handling explicit (valid NaN = missing, all-NULL = error, leading/trailing NULL trim with
correct forecast-step alignment).

Purpose: FCST-01/02/03/08 (D-01, D-02, D-03, D-11, D-12). Every later plan builds on this
passthrough. Rust-only plan — no C++ edit, so no extension build here (the C++ marshalling of
lower/upper already maps an empty vec to a null pointer → SQL NULL in `_ts_forecast_scalar`;
the SQL-level checks land in 10-02's build).
Output: rewritten interval/fitted/residual flow in forecast.rs, extended FFI parity test,
new R-fixture integration test.
</objective>
