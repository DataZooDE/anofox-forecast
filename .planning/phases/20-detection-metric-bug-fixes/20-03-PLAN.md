> **AMENDMENT (2026-10-23, from 20-02 execution, overrides every recipe below):** do NOT use `WITH _ts_src AS MATERIALIZED (...)`. On DuckDB v2.0.0 it intermittently raises `INTERNAL Error: Pipeline broadcast exchange received invalid producer batch index` (12/30 runs). Use the recipe proven in 20-02 instead: pass the native `(SELECT * FROM _ts_passthrough(source) ORDER BY ALL)` as its source (40/40 clean, cheaper), together with the shared `src/include/ts_collect_finalize.hpp` barrier. Every acceptance check of the form `contains "AS MATERIALIZED"` is replaced by `contains "_ts_passthrough(" and "ORDER BY ALL"`. See 20-02-SUMMARY.md and deferred-items.md. API rule (Phase 20.1): public macro signatures and output columns must stay identical (check DESCRIBE before and after).
