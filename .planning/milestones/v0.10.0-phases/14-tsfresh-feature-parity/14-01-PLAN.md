tsfresh PACF (statsmodels 0.15.0): n <= 1 -> NaN; max_lag = n//2 - 1 when the demanded lag >= n//2, lags above
  max_lag -> NaN; pacf(x, method="ld", nlags) = levinson_durbin(acovf(x, adjusted=True, demean=True, fft=False)):
  xo = x - mean; acov[k] = sum_{i=k}^{n-1} xo[i]*xo[i-k] / (n-k)  (k = 0 divides by n). Recursion: RESEARCH.md
  "PACF (Durbin-Levinson)" and the "Code Examples" pseudocode. Lag k's value does not depend on nlags.
tsfresh autocorrelation: NaN if n < lag; sum_product = sum_{i=0}^{n-lag-1} (x[i]-mean)*(x[i+lag]-mean);
  v = np.var(x) (ddof 0); NaN if np.isclose(v, 0) i.e. |v| <= 1e-8; result = sum_product / ((n-lag)*v)
  (lag == n gives 0/0 = NaN).
