statsmodels adfuller algorithm (autolag): maxlag clamp `min(nobs // 2 - ntrend - 1, maxlag)`; fit lags 0..=maxlag on the common sample (nobs = n - 1 - maxlag) with OLS IC (aic = -2 llf + 2k, bic = -2 llf + ln(nobs) k, llf = -nobs/2 (ln 2π + ln(SSR/nobs) + 1), k = regressor count); ties → smaller lag; 't-stat' = start at maxlag, drop lags while |t(last lag)| < 1.6448536269514722; then REFIT at the chosen lag on its full sample (nobs = n - 1 - lag); critical values via mackinnoncrit at that nobs.
urca ur.df with fixed lags k uses the same sample as adfuller(maxlag=k, autolag=None), so fixed-lag statistics must agree with both references (t-stat is invariant to the trend column's offset).
