<interfaces>
R forecast 9.0.2 conventions (verified at planning time from the extension's AirPassengers fixture: MAM loglik -682.4036, aic 1398.807, aicc 1403.664, bic 1449.294, np = 17):
- loglik = −0.5·( n·ln(Σ e_t²) + 2·Σ ln|ŷ_t| [multiplicative error only] ), e_t = y_t − ŷ_t (additive error) or (y_t − ŷ_t)/ŷ_t (multiplicative error), summed over ALL t = 1..n.
- np = length(par) + 1 where par = (alpha, beta, gamma, phi, l, b, s0..s_{m−2}) as applicable — equals the crate's `num_params()` (it already counts m−1 seasonal states and sigma²).
- aic = −2·loglik + 2·np; aicc = aic + 2·np(np+1)/(n − np − 1); bic = aic + np·(ln n − 2).
- sigma2 = Σ e_t² / (n − length(par)) (used for intervals in 11-07).
- Initial states are at time 0 (before y_1). par s0 is the most recent initial seasonal state (lag 1), s{m−2} lag m−1; the oldest (lag m, used by y_1) is implied by normalisation: m − Σ (multiplicative) or −Σ (additive). Expected crate mapping with the seasonal buffer indexed by `t % m` (t = 0 for y_1): buffer[0] = implied oldest state, buffer[k] = par s{m−1−k} for k = 1..m−1. The exact-loglik test validates this mapping — if it fails only for seasonal models, fix the mapping, not the tolerance.
- Usual constraints (ets lower = c(1e-4, 1e-4, 1e-4, 0.8), upper = c(0.9999, 0.9999, 0.9999, 0.98), bounds "usual" part): beta in [lower, alpha], gamma in [lower, 1 − alpha], phi in [0.8, 0.98].
- restrict = TRUE pool: skip errortype "A" with seasontype "M"; skip "M","M","A" (no multiplicative trend exists in this crate); multiplicative error only when min(y) > 0; damped only with a trend. Default ic = "aicc".
- R forecast.ets interval dispatch (for 11-07): class1 = A error, trend N/A(d), season N/A; class2 = M error, trend N/A(d), season N/A; class3 = M error, season M; otherwise simulation.
