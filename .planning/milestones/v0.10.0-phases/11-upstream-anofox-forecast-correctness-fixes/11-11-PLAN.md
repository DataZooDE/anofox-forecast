<interfaces>
R forecast 9.0.2 (read exact code with `Rscript -e 'x<-deparse(forecast::auto.arima); cat(x, sep="\n")' | less` and `Rscript -e 'print(forecast:::myarima)'`, `Rscript -e 'print(stats::arima)'`):
- approximation default = (length(x) > 150 | frequency(x) > 12). AirPassengers (n 144, m 12) → exact for every candidate; RW fixture (n 200) and M4 D4047 → approximation.
- myarima: method = "CSS" when approximation else "CSS-ML". nstar = n - d - D*m; npar = length(coef[mask]) + 1. Exact: aic = -2*loglik + 2*npar; aicc = aic + 2*npar*(npar+1)/(nstar-npar-1); bic = aic + npar*(log(nstar) - 2). CSS (approximation): ic = offset + nstar*log(sigma2) + 2*npar (+ the same AICc term), offset constant across candidates (from an exact ARIMA(1,d,0)(0,D,0) fit) — it matters only when mixing CSS and exact scores, which R never does inside one search.
- stats::arima CSS: ncond = d + D*m + p + P*m; sigma2 = SSR / (number of residuals after ncond); MA residuals start from zero. CSS-ML: CSS optimum is the start; AR start non-stationary → error (candidate gets Inf in auto.arima); ML stage optimises the exact likelihood with transform.pars = TRUE (AR via PACF/Jones transform). Exact loglik on the differenced series w (length nstar): loglik = -0.5*(nstar*log(2*pi*s2) + sum(log v_t) + nstar) with s2 = (1/nstar)*sum(u_t^2/v_t) (concentrated; equals R's 2*n.used*res$value + n.used + n.used*log(2*pi) = -2*loglik).
- Constant: mean when d+D = 0, drift when d+D = 1 (in differenced space both are a constant mean of w, estimated jointly with the ARMA parameters); none when d+D >= 2.
- Root rule (myarima): minroot = min modulus of roots of 1 - sum(phi_i z^i) over the fully expanded seasonal AR and of 1 + sum(theta_i z^i) over the expanded MA (trailing |coef| < 1e-8 trimmed); minroot < 1.01 → ic = Inf.
- After a stepwise search with approximation: refit the best by exact ML; if that refit gives Inf, R reruns without approximation. Non-stepwise: sort by ic and refit in order until a finite exact fit.
- Expanded polynomials: phi(B)*Phi(B^m) and theta(B)*Theta(B^m) (multiplicative SARIMA).
