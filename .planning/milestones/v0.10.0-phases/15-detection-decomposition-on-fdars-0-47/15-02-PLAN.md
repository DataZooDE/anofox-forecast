scipy 1.18.1 find_peaks semantics to port (scipy/signal/_peak_finding_utils.pyx + _peak_finding.py):
  _local_maxima_1d: i = 1; i_max = n - 1; while i < i_max: if x[i-1] < x[i]: i_ahead = i + 1; while i_ahead < i_max and
    x[i_ahead] == x[i]: i_ahead += 1; if x[i_ahead] < x[i]: left = i, right = i_ahead - 1, peak = (left + right) // 2;
    i = i_ahead; i += 1. (A plateau reaching the last sample is never a peak; the first and last samples never are.)
  height: keep peaks with x[peak] >= hmin (inclusive).
  distance: d = ceil(distance) (scipy raises for distance < 1); priority = x[peaks]; order = argsort(priority);
    keep all; for i from the last (highest) to the first: j = order[i]; if !keep[j] continue; k = j - 1; while k >= 0
    and peaks[j] - peaks[k] < d: keep[k] = false; k -= 1; k = j + 1; while k < len and peaks[k] - peaks[j] < d:
    keep[k] = false; k += 1. Ties: numpy's argsort is stable for these sizes, so among equal heights the RIGHTMOST is
    processed first; port with a stable ascending sort by height and iterate from the end.
  prominence (wlen None): left scan from the peak while i >= 0 and x[i] <= x[peak], tracking the minimum; stops at the
    first STRICTLY higher sample; right scan symmetric; prominence = x[peak] - max(left_min, right_min).
    Equivalent O(n): left_min[i] = min of x over (L, i] where L is the nearest index left of i with x[L] > x[i] (or the
    series start) — one left-to-right monotonic-stack pass storing each stack entry's segment minimum; mirror pass for
    the right; prominence = x[p] - max(left_min[p], right_min[p]).
  order of filters: local maxima -> height -> (threshold, unused) -> distance -> prominence (computed on survivors,
    keep >= pmin).
