BOCPD specification (implement identically in numpy and Rust; planner prototype on 2026-10-12 reproduced the
anchors below):
  n < 3 -> InsufficientData; any non-finite value -> InvalidInput.
  sigma_hat = robust_noise_scale(x): d = diff(x); mad = median(|d - median(d)|) (numpy median: mean of the two middle
    values for even length); s = 1.482602218505602 * mad / sqrt(2); if !(s > 0 and finite): s = std(d, ddof 0) /
    sqrt(2); if !(s > 0 and finite): s = 1.0. loc = median(x). z = (x - loc) / s.
  h = 1 / max(hazard_lambda, 1). State over run lengths r = 0..len-1 (r = observations in the run): P (sums to 1),
    cnt, s1, s2; start P = [1], cnt = [0], s1 = [0], s2 = [0].
  For t in 0..n: for each r: n_r = cnt[r]; xbar = s1/n_r (0 if n_r = 0); S = max(s2 - s1^2/n_r, 0) (0 if n_r = 0);
    kappa_n = 1 + n_r; mu_n = s1 / kappa_n; alpha_n = 1 + n_r/2; beta_n = 1 + S/2 + n_r*xbar^2 / (2*kappa_n);
    nu = 2*alpha_n; scale = sqrt(beta_n*(kappa_n + 1) / (alpha_n*kappa_n)); u = (z_t - mu_n)/scale;
    logpred = lnGamma((nu+1)/2) - lnGamma(nu/2) - 0.5*ln(nu*pi) - ln(scale) - (nu+1)/2 * ln(1 + u^2/nu).
    logw[r] = ln P[r] + logpred[r]; m = max(logw); w = exp(logw - m);
    G[0] = h * sum(w); G[r+1] = (1 - h) * w[r]; P' = G / sum(G).
    cnt' = [0] ++ (cnt + 1); s1' = [0] ++ (s1 + z_t); s2' = [0] ++ (s2 + z_t^2).
    If len(P') > 500: P'[499] = sum(P'[499..]); keep the first 500 entries of P', cnt', s1', s2' (index 499 keeps the
    statistics of run length 499); renormalise P'.
    m_t = argmax over r >= 1 of P'[r] (first maximum); prob[t] = P'[1]. P = P', etc.
  Flags: for t >= 1, if m_t < m_{t-1}: i = t - m_t + 1; if 1 <= i <= n-1: is_changepoint[i] = true.
    changepoints = sorted flagged indices; include_probabilities = false still zeroes the probability vector.

  z = x / sigma_hat (same robust_noise_scale). Prefix sums for L2/Normal; L1 uses the segment median.
  L2(a,b) = sum (z - mean)^2; L1(a,b) = 2*sqrt(2) * sum |z - median|; Normal(a,b) = len*(1 + ln(var_mle + 1e-8))

  scanned tau with F(tau) + C(tau,t) > F(t) expires at t + min_size (it can no longer be optimal once t itself is an
  admissible split); t joins the live set. Backtrack from n. cost = F(n) (= total segment cost + beta * #changepoints).
