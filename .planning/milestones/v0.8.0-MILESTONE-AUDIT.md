## Tech debt (non-blocking — see frontmatter for full list)

1. **`ts_cv_forecast_by('AutoEnsemble')` segfault** — the CV native (`ts_cv_forecast_native.cpp:380-388`) zeroes and never parses `ensemble_top_k`/`ensemble_method`, so AutoEnsemble runs with uninitialized ensemble state and crashes (exit 139). Worked around in the EPI-01 example (manual per-fold `_ts_forecast_scalar` loop) and documented. **Recommended follow-up:** wire ensemble param parsing into the CV native (a small, self-contained fix mirroring the Phase 4 scalar/native param plumbing).
2. **AutoEnsemble non-Mean weights → NULL** — crate 0.15.3 exposes no inner-ensemble weight accessor; `ts_auto_ensemble_inspect_by` returns selected members + MSE score with NULL weight for non-Mean methods. Documented; upstream enhancement candidate.
3. **`ts_cv_forecast_by` param-drop for AutoEnsemble** (always top_k=3/Mean) — documented limitation, same root file as (1).
4. **`build_forecaster` SeasonalWindowAverage n_seasons=2** — TODO ENS-03; low impact.

Pre-deferred (declared out of scope at milestone start, not new debt): ENS-F1 (custom weights), ENS-F2 (panel/VAR ensembles), per-member params.
