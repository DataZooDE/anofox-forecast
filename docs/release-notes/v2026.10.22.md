# anofox_forecast v2026.10.22 — macOS build on DuckDB v2.0.0

**anofox_forecast v2026.10.22 fixes the macOS build on DuckDB v2.0.0.** Every SQL
function, signature and numeric result is unchanged from
[v2026.10.21](v2026.10.21.md). No upgrade steps are needed.

## What changed

- **macOS on DuckDB v2.0.0.** The extension now links the macOS `Security` framework,
  which DuckDB 2.0's built-in HTTP client needs. Without it the `osx_arm64` build
  failed to link, so the registry could not publish a DuckDB 2.0 binary for any
  platform. The build and SQL suite now pass on `osx_arm64` against v2.0.0.

See [CHANGELOG.md](../../CHANGELOG.md) for the full entry.
