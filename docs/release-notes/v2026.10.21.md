# anofox_forecast v2026.10.21 — DuckDB v2.0.0

**anofox_forecast v2026.10.21 builds and runs on the final DuckDB v2.0.0 release.**
Every SQL function, signature and numeric result is unchanged from
[v2026.10.17](v2026.10.17.md). No upgrade steps are needed.

## What changed

- **DuckDB v2.0.0 build fix.** The final v2.0.0 release changed how DuckDB passes the
  extension name to an extension's build script, which broke our configure step. The
  build now names its targets explicitly, so it works on v2.0.0 and on 1.x.
- **Full suite on v2.0.0.** All 5591 SQL assertions across 94 test files pass on DuckDB
  v2.0.0.
- **Builds without OpenSSL work again.** Such builds now leave out the banner's
  telemetry hook rather than failing at link time.
- **CI** tests against the `v2.0.0` tag instead of a 2.0-dev snapshot, so registry
  build changes show up in our own CI first.
