# anofox_forecast v2026.11.26 — forecasting with given model parameters

**anofox_forecast v2026.11.26 lets `ETS`, `TSB` and `ARIMA` forecast with externally
supplied parameters, and moves to the `anofox-forecast` crate 0.23.0.** No SQL names,
parameters or output columns were removed or renamed, and results without the new keys are
unchanged.

## Highlights

- **Given model parameters (#317).** For hyper-model forecasting, where a global learner
  predicts the parameters of a classical model, new `params` keys fix those parameters:
  - `ETS` with a `model` spec: `alpha`, `beta`, `gamma`, `phi`. Only the initial states are
    estimated, by maximum likelihood.
  - `TSB`: `alpha_d`, `alpha_p`.
  - `ARIMA` with `arima_order`: `ar_coefficients`, `ma_coefficients`,
    `seasonal_ar_coefficients`, `seasonal_ma_coefficients`, `intercept` (R `Arima`'s mean).

  The values are used exactly. Each key is valid only with its own model, and missing,
  extra or unparsable values are errors. AutoETS's inspected parameters, fed back as fixed
  parameters, reproduce its forecast within 1%.
- **`ts_forecast_inspect_by` accepts a fixed-spec `'ETS'`**, so its parameters and
  estimated initial states can be read back.

Time-varying parameters are not supported yet.
